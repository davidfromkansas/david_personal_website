# Ultra Water (vendored)

The ocean, sky and island renderer behind the home screen's beach, copied from
[Humpalumps/Ultra-Water](https://github.com/Humpalumps/Ultra-Water) at commit
`e58ddcdc18ea779b9386a2e5c76f2c6329c8bab9` (MIT, see `LICENSE` and `THIRD_PARTY_NOTICES.md`).

Only the files the beach uses are kept (no floaters, underwater pass, water query or GPU
timer). The code is unchanged. `../beach.js` builds the scene from these parts.
